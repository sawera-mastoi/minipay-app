# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-04-24

### Added
- Centralized constants for blockchain and app configuration.
- ErrorBoundary component for graceful error handling.
- Spinner and LoadingOverlay UI components.
- Common animation components (FadeIn, SlideIn, PageTransition).
- Skeleton loading components for better UX.
- Tooltip component for UI hints.
- Network compatibility and naming utilities.
- useLocalStorage hook for persistent state.
- Social sharing utilities for Twitter and Web Share API.
- Time calculation utilities for streak window tracking.

### Changed
- Enhanced README.md with detailed project overview and structure.
- Improved MilestoneTracker with type safety and animations.
- Refactored DailyStreak.sol with descriptive variables and events.
- Standardized Button variants and added glassmorphism support.
- Optimized .gitignore for Next.js and Celo.
- Improved ThemeProvider with persistence and SSR safety.
- Refined Card hover effects and shadow intensity.
- Enhanced useToast hook to support multiple concurrent notifications.
- Improved Navbar responsiveness for mobile screens.

### Fixed
- Cleaned up unused imports and optimized page.tsx structure.
- Standardized project metadata and licensing.
